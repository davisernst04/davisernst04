## Featured Projects

### [TypeScript Game Boy Emulator](https://github.com/davisernst04/typescript_gameboy_emulator)
A Game Boy emulator core for browser and Node.js applications, published as an [npm package](https://www.npmjs.com/package/typescript-gameboy-emulator).

- Implements the complete Sharp LR35902 CPU instruction set and a scanline-based PPU renderer
- Supports MBC0, MBC1, MBC3, and MBC5 memory banking with 50+ compatible commercial ROMs
- Validated against standard test-ROM suites in a headless Node.js environment
- **[Try the browser demo](https://emulator-demo.vercel.app)**

### [Real-Time Game Analysis](https://github.com/ElleOwO/realtimegamestatistics)
A real-time analysis platform for the University of Saskatchewan women's soccer team, developed with the USask Sports Engineering Club.

- Contribute to an object- and keypoint-detection pipeline
- Built a Next.js interface for live metrics and visual overlays
- Stream model-inference output from FastAPI over WebSockets

### [Shadow Basketball Registration Platform](https://github.com/davisernst04/basketball-registration-platform)
A deployed registration platform for a local youth basketball club.

- Public player-registration and tryout-scheduling workflows
- Administrative dashboard with session and capacity management
- Supabase authentication, role-based access control, PostgreSQL migrations, and automated deployment
- **[Visit the live site](https://basketball-registration-platform.vercel.app)**
